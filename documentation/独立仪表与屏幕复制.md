# 独立仪表与中控区域复制

在「显示」右侧打开 **软件仅作为仪表**。开关默认关闭；开启后停止已有手机互联，并阻止手动连接、开机连接、蓝牙预连接和自动重试。仪表继续显示车辆数据，CarPlay 模式下仍使用原有导航地图流。

在「显示 → 仪表管理」中，每种风格都有 **复制中控区域作为地图** 入口。都市、运动和原始风格分别保存区域，无需单独打开复制开关。按住矩形内部移动，拖动任意角缩放；中央按钮可一键全屏、居中或返回。选中画面会拉伸铺满该风格固定的地图窗口，不改变仪表窗口大小。

开启仅仪表模式后自动请求 Android 屏幕录制授权；授权后自动复制当前风格保存的区域。切换仪表风格复用现有采集会话，改用对应区域，不重复申请授权。若此前拒绝或停止采集，可在框选页点击 **授权屏幕复制** 再次授权。切换至其他应用后，仪表继续显示选中的中控区域；安全窗口和受保护的视频内容由系统限制，不能复制。授权仅用于本次运行，不保存或重复使用授权令牌。

采集使用公开的 `MediaProjection`、`VirtualDisplay` 和 `ImageReader`，保持系统提供的原始分辨率，最多更新约 30 帧/秒。工作线程只取最新帧，处理行填充后及时关闭图像；使用固定大小的像素缓冲，避免帧队列和逐帧内存分配。尺寸变化时调整已有 VirtualDisplay 并替换输出资源，以兼容 Android 14 的单次创建限制。

后台采集由 `mediaProjection` 类型前台服务承载。可通过通知中的「停止复制」、关闭仅仪表模式或系统录屏入口停止。停止、系统撤销授权或异常时会释放采集资源；需要再次使用时重新授权。Android 14 及以上请求整个默认中控屏幕，以保持框选坐标一致。

## 原车音乐读取与导航限制

依据维护者提供的参考包，仅仪表模式通过标准 ContentResolver 只读查询 `content://ltd.qisi.datasync.datasyncProvider/domainValue_table`。识别 `media_name`（歌名）、`media_artist`（歌手）、`media_ablum`（专辑，保留固件拼写）、`media_source`（音源）和 `media_playstate`（布尔播放状态）。已知音源枚举显示为可读名称，未知值原样保留。三个风格共用系统音乐状态，不更改各自的字体、颜色和组件布局；CarPlay 仍使用原有数据源。

Provider 的真实表结构尚未实车核实。实现检查运行时列名，兼容已知字段直接作为列，以及候选键值列组合（`key/value`、`name/value`、`domain/value`、`domainKey/domainValue`、`domain_name/domain_value`）；同时识别参考包说明的默认 displayId 0 键名后缀。只有实际列或行键匹配参考字段时才消费，不支持的结构或冲突记录不会任意取值。Provider 只作为持久化辅助查询，不能保证实时；参考包说明的 Qisi SDK 才提供单项读取和变更订阅，但 SDK/AIDL 未随参考包提供，因此本项目不伪造依赖或反射调用未知类型。当前播放状态按布尔文本读取，不把未知数字当作播放枚举；没有封面、歌词、时长或进度字段。

首次订阅、变化通知和约两秒的补偿轮询均在专用工作线程执行，失败后约五秒重试；仪表释放订阅后取消查询、注销观察者并清空缓存。Provider 缺失、拒绝访问或返回异常时降级为空音乐。诊断开关控制日志与报告，记录列结构和读取可用性，不记录歌曲内容。

固件线索中的服务为 `ltd.qisi.datasyncservice/ltd.qisi.datasyncservice.DataSyncService`。未提供 SDK/AIDL，因此不绑定该服务、不发送 Binder 事务，也不调用猜测的管理器方法。即使静态声明 exported 且无访问权限，运行时可读性仍需目标车机验证。

参考包列出导航字段 `navigation_status`、`navi_current_state`、`navi_start`、`navi_target`、`navi_info_distance`、`navi_info_time`、`navi_arrive_time`、`navi_arrive_time_day_num`。本地实现读取已知目标、格式化距离/用时/到达时间，并以文字摘要显示；这些距离和时间是格式化字符串，不转换成米或秒。当前没有按未说明的状态值合成转向图标、车道或路口动作。参考包提到的 `navi_tbt_info` 未证实原厂实际发布，故不订阅。手册的 `sendMusicInfoToCluster` 和 `sendNaviInfoToCluster` 是发送接口，不能用来读取系统当前状态。上述 Provider 接入仅经本地测试，未在实车验证。

采集不会录制音频、保存视频或上传画面。诊断事件受诊断日志开关控制，不记录画面内容或授权数据。真实飞屏仍需要车辆提供仪表显示器；单屏模拟器可以检查设置和系统授权流程，不能替代实车验证。
